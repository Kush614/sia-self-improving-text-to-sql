From one chain to a population

SIA improves a single agent sequentially (75.8% → 95.0% over 8 generations). Phylo evolves a population of agent harnesses — selection, crossover, mutation, migration — exploring many lineages in parallel and exposing the search as a live 3D phylogeny.

— → —
population search

1 · The loop

Each generation: evaluate every harness on the same held-out Spider set (real execution accuracy, reusing SIA's verifier) → select the top performers → recombine their genome sections (crossover), mutate with Claude/GPT-5, occasionally migrate a strong agent between populations, and carry the elite forward. A harness genome has five recombinable sections: system_prompt, tool_definitions, meta_instructions, error_handling, output_format.

2 · Sponsor stack — what each one does

CopilotKit · AG-UI

  • Next.js runtime + live AG-UI connection
  • useCopilotReadable exposes the live phylogeny + selected node
  • generative-UI actions: ancestor-diff + an in-chat live harness editor
  • chat sidebar to interrogate any agent's lineage

Redis

  • genomes → hashes; fitness → sorted sets (O(log N) top-K)
  • lineage → parent/child sets
  • RedisVL vector search over genome embeddings (similar harnesses)
  • pub/sub → SSE → live 3D tree; cache memoizes identical calls

Weave / W&B

  • every target + mutation call traced (tagged agent/gen/pop/op)
  • per-generation fitness dashboards
  • MCP server for run inspection + per-node trace deep-links

OpenAI + Anthropic

  • Anthropic Haiku = fixed target model; Sonnet = mutation
  • OpenAI GPT-5 = diverse mutation strategy
  • OpenAI embeddings feed the Redis vector index

5 · Live harness editor (cached demo)

The evolved winner's harness vs the cold-start seed. Switch sections, switch seed/best, edit freely — this is the prompt-only scaffold that drove the climb (the model never changed).

6 · How it plugs back into SIA

Phylo reuses SIA's exact Spider data + execution-accuracy verifier, so it's evolving harnesses for the SIA text-to-SQL task. The bridge export_to_sia.py takes Phylo's best genome and emits a SIA-compatible target_agent.py + target profile, so SIA seeds its next run from the evolved harness instead of the minimal one. Phylo searches; SIA runs the winner.
